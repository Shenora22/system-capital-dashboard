# Pricing Structure

## Standard Build

**Price:** $1,500 to $3,500 depending on complexity.

Includes:

- Lead intake workflow.
- Pipeline setup.
- Follow-up structure.
- Outreach message templates.
- Basic reporting dashboard.
- Client handoff documentation.
- One implementation review call.

## Pilot Build

**Price:** $750 to $1,250.

Best for prospects who want to validate the system before committing to a larger rollout.

Includes:

- A simplified lead tracker.
- One lead source workflow.
- Basic follow-up template set.
- One short handoff guide.
- One review call.

## Monthly Support Option

**Price:** $300 to $750 per month.

Includes:

- Light system adjustments.
- Template refinements.
- Pipeline cleanup.
- Monthly performance review.
- Recommendations for improving lead handling.

## Pricing Notes

Pricing should be framed around revenue leakage, missed follow-up, and owner time saved rather than software setup alone.
