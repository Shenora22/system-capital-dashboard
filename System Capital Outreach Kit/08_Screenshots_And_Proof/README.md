# Screenshots And Proof

Use this folder to store supporting proof for outreach and sales conversations.

Suggested assets:

- Before-and-after screenshots of lead trackers.
- Pipeline dashboard examples.
- Client workflow diagrams.
- Loom audit thumbnails.
- Testimonials or anonymized results.
- Screenshots of follow-up reminders or reporting views.

Do not include private client data unless it has been approved for use.
