# SkyTrace pitch asset guide

Use these assets as visual proof that the `/drone` mission-control MVP already packages drone telemetry, AI review cues, and human-approved automation into an investor-ready operations cockpit.

## Recommended slide placement

### 1. Product hero / opening demo

- **Asset:** `public/pitch-assets/skytrace-dashboard-hero.png`
- **Use on:** Product intro, demo teaser, or “What we built” slide.
- **Crop suggestion:** Use the full image or a 16:9 center crop that keeps the SkyTrace header, KPI cards, map, and selected asset panel visible.
- **Caption suggestion:** “SkyTrace turns live drone telemetry into a mission-control cockpit for alerts, recommendations, and review-only actions.”

### 2. Situational awareness

- **Asset:** `public/pitch-assets/skytrace-map-view.png`
- **Use on:** Operations workflow, market problem, or situational-awareness slide.
- **Crop suggestion:** Keep the full tactical map with drone markers and the simulated GPS layer note; crop lightly from the top only if the slide needs extra text space.
- **Caption suggestion:** “Fleet positions, airspace context, and active risk markers in one operator map.”

### 3. AI risk detection and review

- **Asset:** `public/pitch-assets/skytrace-alerts-panel.png`
- **Use on:** AI differentiation, safety, compliance, or risk-detection slide.
- **Crop suggestion:** Use a vertical crop focused on the critical and high-severity cards when space is limited.
- **Caption suggestion:** “AI triages alerts with severity, confidence, and field context before operators act.”

### 4. Fleet telemetry data layer

- **Asset:** `public/pitch-assets/skytrace-telemetry-panel.png`
- **Use on:** Data platform, ingestion roadmap, or technical architecture slide.
- **Crop suggestion:** Use the full telemetry table for data-rich slides; crop to the first three rows for a cleaner split layout.
- **Caption suggestion:** “Structured drone telemetry is ready for API ingestion, Supabase persistence, and analytics expansion.”

### 5. Human-in-the-loop automation

- **Asset:** `public/pitch-assets/skytrace-automation-panel.png`
- **Use on:** Automation, control, governance, or enterprise trust slide.
- **Crop suggestion:** Keep both the selected asset card and action log so the slide shows decision context plus auditability.
- **Caption suggestion:** “Actions are staged for human review, creating an auditable path from recommendation to operator approval.”
