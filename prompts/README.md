# Prompts Subsystem

The prompts subsystem is reserved for versioned LLM prompt packs, agent instructions, and evaluation notes.

## Intended Structure

- `agents/` — agent role prompts and policies.
- `automation/` — prompts used to translate SOPs into workflow steps.
- `marketing/` — content generation and campaign prompts.
- `evaluations/` — prompt test cases and scoring rubrics.
