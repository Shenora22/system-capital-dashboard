# Workflows Subsystem

The workflows subsystem documents business processes that can be executed by agents or automation engines.

## Relationship to Automation

- `workflows/` explains process intent, ownership, SLAs, inputs, and outputs.
- `automation/n8n/workflows/` stores executable n8n JSON exports.
